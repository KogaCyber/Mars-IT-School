# Shriftlar

Figma maketida `Actay` va `Actay Wide` shriftlari ishlatilgan.
Litsenziyalangan fayllarni shu papkaga quyidagi nomlar bilan joylang:

- `actay-regular.woff2` — asosiy matn (Actay Regular)
- `actay-wide-bold.woff2` — sarlavhalar (Actay Wide Bold)

Fayllar bo'lmasa sayt ishlashda davom etadi: `src/assets/styles/fonts.css`
zaxira shriftlar ro'yxatini belgilagan.
