# Архитектура сайта школы (решение от 2026-09-14)

## Принцип: читаем из LMS, пишем к себе

Сайт — витрина школы. Всё, что уже есть в LMS (геймификация, `gamification_db`,
PG 13 :5432), **не дублируется** — читается напрямую ролью только на чтение.
Всё, что нужно только сайту, живёт в **своей** базе (`mars_it_school`, PG 17
:5437) и привязано к записи LMS по `id`.

| Сущность сайта | Читаем из LMS | Своя таблица (надстройка) |
|---|---|---|
| Курс | `courses_program` — название, описание, `on_sale` | `site_course` → `program_id`: slug, тексты ×3, картинки, цена, возраст, длительность, этапы, фичи, FAQ |
| Преподаватель | `users_teacher` — имя, фамилия | `site_teacher` → `teacher_id`: фото, должность ×3, био ×3, соцсети, навыки |
| Филиал | `companies_company` — название uz/ru, фото, slug | `site_branch` → `company_id`: адрес ×3, ориентир, часы, телефон, координаты, галерея |
| Вакансия | `department_vacancy` — uz/ru тексты, картинка | `site_vacancy` → `vacancy_id`: en-тексты, условия, тип занятости, зарплата |
| Новость | — (`companies_news` — внутренняя лента LMS) | `site_news` целиком |
| Тест | — (`quiz_*` в LMS — другая модель) | `site_quiz*` целиком |
| Заявка, отклик, секции страниц, настройки, FAQ, отзывы, преимущества… | — | свои |

LMS-роль `school_ro`: `SELECT` ровно на четыре таблицы. `users_user` не выдаётся
(там хеши паролей). Сайт **физически не может** писать в LMS.

## Стек

FastAPI + SQLAlchemy 2 (async) + asyncpg + Alembic + Pydantic v2. Python 3.10
(потолок на mars). Два движка: `lms` (read-only) и `site`.

API-контракт — тот же, что у прежнего Django-бэкенда: пути `/api/v1/…`,
формы ответов, `?lang=`, пагинация новостей. Vue-фронт не меняется.

## Админка — визуальный редактор

Не отдельная панель: админ открывает страницу сайта, включает режим правки,
кликает по тексту или картинке и меняет на месте (модель «секций» уже есть).
Сущности — форма «Добавить», где LMS-часть выбирается из списка (программа,
преподаватель, филиал), остальное заполняется руками.

## Этапы

1. FastAPI с полным API-контрактом → сайт переключается, Django выключается.
2. Редактор страниц (секции, картинки).
3. Формы «Добавить» для курса / вакансии / новости / преподавателя.
